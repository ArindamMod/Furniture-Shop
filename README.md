# Furniture Shop

A full-stack furniture e-commerce website built with Django 5, Bootstrap 5, SQLite, and Razorpay Test Mode.

## Features

- User registration and login
- User account page
- Product categories
- Product listing and product details
- Shopping cart
- Increase/decrease cart quantity
- Remove products from cart
- Checkout with delivery information
- Razorpay Test Mode payment integration
- Payment verification
- Order creation
- Order history
- Order details
- Order status viewing
- Django admin panel
- Jazzmin admin interface
- Product and category management
- User and order management
- Responsive Bootstrap 5 interface

## Technologies Used

- Python 3.12
- Django 5.0
- Bootstrap 5
- HTML5
- CSS3

- SQLite
- Pillow

## Installation

### 1. Clone the repository

```bash
git clone <your-github-repository-url>
cd furniture_shop
```

### 2. Create a virtual environment

Mac/Linux:

```bash
python3 -m venv venv
```

Activate it:

```bash
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Create the environment file

Create a file named:

```text
.env
```

Use `.env.example` as the template.

Example:

SECRET_KEY=your-secret-key
RAZORPAY_KEY_ID=your-razorpay-key-id
RAZORPAY_KEY_SECRET=your-razorpay-key-secret

DEBUG=True

ALLOWED_HOSTS=localhost,127.0.0.1

SECURE_SSL_REDIRECT=False
SESSION_COOKIE_SECURE=False
CSRF_COOKIE_SECURE=False

SECURE_HSTS_SECONDS=0
SECURE_HSTS_INCLUDE_SUBDOMAINS=False
SECURE_HSTS_PRELOAD=False


Do not commit `.env` to GitHub.

### 5. Apply migrations

```bash
python manage.py migrate
```

### 6. Create an admin user

```bash
python manage.py createsuperuser
```

Follow the prompts to create the admin account.

### 7. Start the development server

```bash
python manage.py runserver
```

Open: http://127.0.0.1:8000/


Admin panel:http://127.0.0.1:8000/admin/


## Razorpay Test Mode

The project uses Razorpay Test Mode for development and testing.

Add your Razorpay Test API credentials to `.env`:

RAZORPAY_KEY_ID=your-test-key-id
RAZORPAY_KEY_SECRET=your-test-key-secret


Never commit real API credentials or secret keys to the repository.

## Important Notes

* `db.sqlite3` is intentionally excluded from Git.
* `venv/` is excluded from Git.
* `.env` is excluded from Git.
* `staticfiles/` is excluded from Git because it is generated by `collectstatic`.
* Each developer should create their own virtual environment and `.env` file.
* Razorpay should remain in Test Mode during development.

## Development

Run Django checks with:

```bash
python manage.py check
```

Check deployment-related Django warnings with:

```bash
python manage.py check --deploy
```

Collect static files when required:

```bash
python manage.py collectstatic --noinput
```
